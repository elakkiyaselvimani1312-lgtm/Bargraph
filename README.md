# Bar Graph Project

This project is a simple Python program to create a **Bar Graph** using Python libraries like `matplotlib`.

## 📌 Objective

To visualize data in the form of a bar chart using Python.

## 🛠️ Technologies Used

* Python
* Matplotlib

## 📂 File Included

* `task1.py` → Python program for generating a bar graph

## ▶️ How to Run

1. Install Python on your system.
2. Install matplotlib using:

```bash
pip install matplotlib
```

3. Run the program:

```bash
python task1.py
```

## 📊 Output

The program displays a bar graph representing the given data values.

## 📖 Example

The graph may show:

* Student marks
* Sales data
* Product comparison
* Any categorical data

## ✅ Result

A bar graph is successfully generated and displayed using Python.
